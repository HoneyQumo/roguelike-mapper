# Roguelike Mapper

Редактор карт для игры [HoneyQumo/roguelike](https://github.com/HoneyQumo/roguelike). Рисуешь комнату или целую локацию, на выходе получаешь готовый файл `.config` для игры.

Чистые HTML, CSS и JS - ни сборки, ни зависимостей.

## Как запустить

Скачать репозиторий и открыть `index.html` двойным кликом. Всё.

Онлайн: https://honeyqumo.github.io/roguelike-mapper/

## Два режима

**Комната** - сетка с кистью и палитрой. Тайлы, объекты, враги, предметы, двери, точки патруля. Легенда собирается сама, символы раздаются автоматически - руками их держать не надо.

**Карта** - раскладываешь комнаты по сетке и видишь локацию целиком, так, как её видит игрок. Границы комнат прячутся галочкой. Несовпавшие стыки подсвечиваются.

## Как открыть то, что уже есть

Кнопка «Выбрать файлы» в правой колонке - выделяешь файлы комнат из `Roguelike/Resources/Rooms` и файл акта из `Roguelike/Resources/Acts`. Комнаты попадут в библиотеку, акт разложится по сетке.

Одну комнату можно вставить текстом в поле справа и нажать «Загрузить из поля».

Символы из исходного файла запоминаются, поэтому файл выходит обратно таким же - без лишних изменений в diff.

## Что проверяется на лету

| Находка | Что значит |
|---|---|
| кусок отрезан | до части комнаты не дойти |
| дыра в границе | по краю карты можно выйти наружу |
| сюда не дойти | клетка недостижима от старта |
| дверь - ключа не достать | ключ лежит позже своей двери |
| не сходятся по строке | комната открывается в стену соседа |
| нет такого объекта | в файле упомянут объект, которого нет в каталоге игры |

Это те же правила, что в тестах игры. Проверки геометрии и данных - сложность боя и поведение врагов тут не увидеть, это только в игре.

## Как обновить данные из игры

Палитра, тайлы и каталоги берутся из репозитория игры, а не переписаны руками. Поменялись каталоги - перегнать:

```
python tools/sync.py ../Roguelike/Roguelike
```

Аргумент - путь к папке `Roguelike` внутри репозитория игры. Скрипт кладёт всё в `data/assets.js`: тайлсеты и атласы объектов как data-URI, списки объектов, предметов и врагов. Нужны Python 3 и Pillow не нужен - хватает стандартной библиотеки.

## Устройство

```
index.html        разметка
style.css         оформление
js/model.js       сетка, клетки, раскладка атласа
js/config.js      чтение и запись .config
js/render.js      отрисовка на canvas
js/checks.js      проверки
js/app.js         интерфейс
data/assets.js    данные из игры, генерируются
tools/sync.py     генератор
```
